# Load the TradingView Extension

Use this when you want the least-fussy path on Mac or Windows.

## MacBook

1. Download `dist/quantum-tradingview-capture-extension.zip` from this repo.
2. Unzip it.
3. Open Chrome.
4. Go to `chrome://extensions`.
5. Turn on `Developer mode`.
6. Click `Load unpacked`.
7. Select the unzipped extension folder.
8. Open the extension, paste your QUANTUM endpoint and API token from Settings, then click `Save connection`.
9. Open TradingView and click the floating `Journal` button.

## Windows

Use the same steps. The only difference is where your Downloads folder lives.

## After Codex Updates the Extension

Download the latest ZIP, unzip it, then go to `chrome://extensions` and click the reload icon on the extension card.
